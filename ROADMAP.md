# Roadmap

Clew is a local-first, Git-like what-if debugger for Python agent traces. The roadmap is
shaped by reproducible community use cases rather than download counts.

## Near term

- Make the first trace, replay, and diff workflow simpler for new users.
- Expand examples for LangChain, OpenAI, Anthropic, MCP, and OpenTelemetry.
- Improve portable trace sharing and safe redaction guidance.
- Keep release artifacts reproducible across supported Python versions and operating systems.

## Exploring

- A small, stable plugin surface for third-party integrations.
- Better trace search and comparison for larger local stores.
- Community-maintained recipes and example agents.

## How to influence it

Open a Discussion with the problem, a minimal reproduction or workflow, and what success
would look like. Small focused pull requests are welcome; see `CONTRIBUTING.md` first.
